
# Heart-Disease-Prediction


The Heart Disease Prediction System is a Machine Learning-based application that predicts the likelihood of heart disease in patients based on their medical and health-related parameters.

The project uses various classification algorithms and compares their performance to identify the best predictive model. Logistic Regression achieved the highest accuracy and was selected as the final model for prediction.

The trained model is integrated with a Streamlit web application that allows users to enter patient details and receive real-time predictions along with probability scores and risk-level visualization.

## Features

- 🩺 Predict the possibility of heart disease using Machine Learning
- 📊 Compare multiple classification models
- 🤖 Logistic Regression selected as the final prediction model
- 📈 ROC Curve analysis and model evaluation
- 🔍 Feature importance analysis
- 📋 Displays patient information summary
- 📊 Shows prediction probability and risk level
- 📥 Download prediction report
- 🌐 Interactive Streamlit web interface

## Machine Learning Models Used

The following classification algorithms were evaluated:

- Logistic Regression
- Naive Bayes
- Support Vector Machine (SVM)
- K-Nearest Neighbors (KNN)
- Random Forest
- Decision Tree

## Model Performance

| Model | Accuracy |
|-------|----------|
| Logistic Regression | 85.25% |
| Naive Bayes | 83.61% |
| SVM | 81.96% |
| KNN | 80.33% |
| Random Forest | 80.33% |
| Decision Tree | 65.57% |

**Best Model: Logistic Regression (85.25% Accuracy)**
